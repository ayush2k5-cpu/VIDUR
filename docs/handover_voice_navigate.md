## Implementation Specs (Phases 1-5)

### Phase 1: Initial Entry Screens
**Task 1A: `lib/voice/qr_scanner_screen.dart`**
- **UI:** Full-screen viewfinder using `mobile_scanner` (`MobileScannerController`). Gold corner brackets (`#E8A020`), `#0C0C0E` background.
- **Logic:** Parse QR JSON payload for `venueId` and `venueMapUrl`.
- **Integration:** Use Riverpod to interact with `SessionRepository` and `NavigationEngine`.
- **Display:** Show the 4-digit PIN generated by the session repository (in JetBrains Mono Bold) so the companion can join.
- **Feedback:** Audio and haptic confirmation on successful scan.

**Task 1B: `lib/voice/destination_input_screen.dart`**
- **UI:** Animated 5-bar gold waveform visualizer.
- **Logic:** Speech-to-text integration (`speech_to_text`) for destination input.
- **Integration:** Riverpod-compatible constructor taking a `NavigationEngine`. Send the parsed destination to the engine.
- **Feedback:** Voice confirmation via `flutter_tts` ("Got it. Navigating to...").

### Phase 2: Core Services
**Task 2A: `lib/navigate/audio_service.dart`**
- Implement text-to-speech using `flutter_tts`.
- Implement spatial binaural audio cues for waypoints using `just_audio`. 

**Task 2B: `lib/navigate/volume_button_service.dart`**
- Intercept hardware volume keys (LogicalKeyboardKey) to map to in-app actions (e.g., repeat last instruction, trigger help).
- Provide structural haptic feedback patterns upon keypress.

### Phase 3: Main Navigation UI
**Task 3A: `lib/navigate/navigate_main_screen.dart`**
- The primary real-time navigation interface.
- Import and display `MandalaWidget` from `lib/components/mandala_widget.dart`.
- Bind Riverpod state to the Mandala and the incoming instructions from `NavigationEngine`.

### Phase 4: Mocking & Verification
**Task 4A: Mock Triggers**
- Implement logic to intercept the current position and manually trigger a hanging obstacle alert when the user physically reaches `waypoint_hanging_001`.
- Ensure this writes the `hangingObstacleTriggered = true` flag to Firebase (sessions/[PIN]) to alert the Companion app.

### Phase 5: Reliability & Performance
**Task 5A: `lib/navigate/navigation_foreground_service.dart`**
- Integrate `flutter_foreground_task`.
- Keep the Voice & Navigate module active and processing position streams even when the app is backgrounded/screen locked.
